## About Marhaba Vox

**Marhaba Vox** is a Windows desktop application engineered for music producers, audio engineers, vocalists, and content creators. Built with Meta's state-of-the-art **Demucs v4 (`htdemucs`)** neural source separation architecture, Marhaba Vox allows you to isolate pristine vocal performances, crystal-clear acapellas, and backing instrumentals directly on your PC with zero cloud dependency.

## ⚡ Key Features

- **100% Offline AI Operation:** Pre-bundled neural model weights (`955717e8.safetensors`). No internet connection or cloud API calls required.
- **Vocal Remover (2-Stem):** Cleanly splits any mixed song into isolated vocals and high-fidelity instrumental backing.
- **Acapella Extractor (Solo):** Dedicated solo vocal isolation optimized for speech, podcasts, and harmonies.
- **Batch Processing Queue:** Add multiple audio tracks and monitor queue status, progress percentage, and time remaining.
- **Interactive Audio Comparison:** Instant A/B stem previewing with synchronized seeking and interactive waveforms.
- **Hardware Acceleration:** Auto-detects NVIDIA CUDA GPUs for rapid inference, with automatic failover to multi-core CPU.
- **No Dependencies Required:** Complete standalone Windows installer bundles embedded Python runtime, PyTorch engine, static FFmpeg binary, and user-friendly GUI.

## 📥 Download & Installation

Download the official standalone Windows setup installer from the [GitHub Releases](https://github.com/Arslan6968/Marhaba-Vox/releases) page:

👉 **[Download MarhabaVox-Setup.exe](https://github.com/Arslan6968/Marhaba-Vox/releases/latest)**

### Quick Install Guide:
1. Download `MarhabaVox-Setup.exe`.
2. Run the installer and choose **Install for All Users** or **Install for Me Only**.
3. Launch Marhaba Vox from your Desktop or Start Menu.
4. Drag and drop any MP3, WAV, FLAC, M4A, or AAC file to begin separating audio.

For detailed instructions, see [INSTALLATION.md](INSTALLATION.md).

## 💻 System Requirements
